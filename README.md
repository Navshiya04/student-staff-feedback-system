# Student Staff Feedback System

## Overview
A Java-based Student Staff Feedback System that enables students to submit feedback on faculty members while allowing administrators to manage users, analyze feedback, and generate performance reports.

## Features
- Student Login and Registration
- Faculty/Staff Management
- Feedback Submission
- Rating System
- Admin Dashboard
- Report Generation
- MySQL Database Integration

## Technologies Used
- Java
- Java Swing
- MySQL
- JDBC
- Git & GitHub
